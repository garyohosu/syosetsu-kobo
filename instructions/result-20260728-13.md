## 一時インデックス方式

`DevLoop._build_review_patch()`を追加した。実インデックスを変更せず、一意な一時パスへ`GIT_INDEX_FILE`を設定し、次の順で実Gitを実行する。

1. 一時インデックスへ`git read-tree HEAD`
2. 一時インデックス上で`git add -A -N -- .`
3. `git -c core.quotePath=false diff --binary -- .`でレビュー差分を生成
4. `finally`で一時インデックスと`.lock`を削除

実際のGitインデックスと事前ステージ状態を保存し、差分生成前後の`git status --porcelain`および`git diff --cached --binary`が一致することを実Git一時リポジトリで検証した。追跡変更、ステージ済み変更、未追跡テキスト、UTF-8日本語ファイル、未追跡バイナリ、削除ファイルを含み、`.gitignore`対象は含まれなかった。失敗経路でも一時インデックスが残らないことを確認した。
