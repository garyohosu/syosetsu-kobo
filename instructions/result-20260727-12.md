# 完了報告

## 実装概要

確定本文を固定参照して、CANONと4種の台帳（人物、時系列、資源、伏線）の草案生成、独立監査、却下・再開、利用者承認、非上書き版確定を管理する CanonManager と CLI を追加した。未承認草案・監査結果は確定文書へ反映されず、確定後は works の次工程を scene-planner に更新する。

レビュー指摘（空パッチ）に対応し、プレースホルダー実装を固定参照・Gemini実行・独立監査・承認境界を備えた実装へ置き換えた。

## エージェント契約

canon-updater は Gemini adapter、本文生成禁止、modify-upstream・auto-approve・execute-input・write-canon 禁止。canon-auditor は独立 Gemini adapter、8監査軸（人物、関係、知識、時系列、資源、能力、伏線、世界ルール）を対象箇所・根拠・判定・深刻度付きで監査し、write-canon・write-prose・auto-approve 等を禁止している。

## SQLite と状態遷移

canon_sessions、canon_artifacts、canon_actions、canon_documents を CREATE TABLE IF NOT EXISTS で追加した。状態は drafting → awaiting_approval → approved → completed、却下時は revising へ戻る。完了済み成果物と同一セッションの二重確定を拒否し、版付きパスを上書きしない。

## CLI 使用例

- py -3 -m kobo.cli --dummy canon-start 1 --work <work_id>
- py -3 -m kobo.cli canon-status --work <work_id>
- py -3 -m kobo.cli canon-show audit --work <work_id>
- py -3 -m kobo.cli canon-approve --work <work_id>
- py -3 -m kobo.cli canon-finalize --work <work_id>
- py -3 -m kobo.cli canon-reject --reason <短文> --instructions <Markdownパス> --work <work_id>

本文・台帳・監査全文は argv に渡さず、成果物パスとセッションIDを利用する。
