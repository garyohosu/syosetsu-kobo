
## 修正2: 治療禁止令とギルベルトの法的権限

次の制度として確定する。

- 治療禁止令への違反は「有罪確定時に極刑となり得る重罪」であり、**発見した武官がその場で自動的に処刑する制度ではない**。
- 逮捕、証拠保全、事情聴取、護送は武官が行える。
- 有罪認定と刑の決定は、地方司法官または王都の法廷が行う。
- ギルベルトは追放護送の責任者として、護送対象者の生命、事件現場、証拠を保全する権限と義務を持つ。
- 今回はギルベルト自身が患者であり、襲撃の被害者かつ証人でもあるため、その場で公平な処分を決定できない。
- 襲撃が追放命令と関係する可能性があり、エレナを直ちに引き渡すと証拠や証人が消される危険がある。
- そのためギルベルトは治療禁止令違反を**正式に認識・記録したうえで**、エレナを「監視付きの暫定拘束状態」に置き、処分を保留する。
- エレナの違反を**免罪したのではない**。襲撃事件の調査終了、または安全な司法機関への引渡しまで判断を留保しただけである。
- ギルベルトが監視を名目に同行するのは、エレナを守るためだけでなく、**逃亡防止、再違反監視、証拠保全**の意味も持つ。

「ただのスープだから治療ではない」という解釈を、**法的な解決には使用しない**。エレナが強がって「ただのスープ」と呼ぶことはできるが、ギルベルトは治療行為だったと理解している。

## 修正3: 王都とガルディニアの距離・移動時間

内部設定として次を確定する。

| 項目 | 値 |
|---|---|
| 王都〜辺境都市ガルディニア（主要街道） | 約480キロメートル |
| 緊急伝令（宿駅で馬を替える健康な騎手） | 通常8〜10日 |
| 通常の官用馬車・旅人（休息含む） | 16〜20日 |
| 薬草・物資を運ぶ商隊 | 22〜28日 |
| 冬季、豪雨、街道封鎖時 | さらに数日〜十日程度遅延 |
| 王都との定期官便 | 月1回 |
| 緊急便を使える主体 | 地方長官、軍、認可された治癒術師組織などに限る |
| 患者記録・治療実績が王都で評価されるまで | 往復と審査を含め最低1か月半〜2か月 |

- ベルナール側は、宿駅、官便、受理組織のいずれかで記録の遅延、差止め、改ざんを試みられる。
- この時間差により、エレナが一件の功績だけで即座に復権することはない。

これらは作者側の整合性を保つための内部設定である。**本文で距離や日数を一度に説明する前提にしない。** 「返事は次の官便まで来ない」「王都へ届くのは早くても十日後」など、必要な場面で行動や会話から示す。
