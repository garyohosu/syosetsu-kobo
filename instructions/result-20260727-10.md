# 実装結果: 章・シーン設計と本文制作工程

確定プロットから章・シーンを設計し、Gemini専任の本文初稿、別担当の独立監査、Geminiによる部分改稿、差分再監査、利用者承認、版付き本文確定までを実装した。

- `scene-planner`を追加し、章設計と場面仕様を本文から分離
- `writer`だけがGeminiで初稿・改稿を担当
- `prose-reviewer`がGeminiで本文を書き換えず独立監査・差分再監査を担当
- 初稿、監査、改稿、再監査、確定本文を別ファイルに保存
- SQLiteへ本文制作セッション、成果物、承認、確定文書を追加
- 中断再開、メール系列、章番号重複拒否、非上書き版管理を実装
- JSON CLI、決定的なダミー工程、自動テスト、仕様書、READMEを更新

自動改稿は初期実装として1回とし、正式な改善停止条件は確定していない。確定本文から正史・台帳を更新する工程は対象外である。
